1. Identify yourself

Uploads are signed with your Nostr key. The site only displays photos published by the creator key configured in data/nostr.json, so nobody else can add photos.

Paste nsec key instead

Your key is kept in memory only — it is never written to storage and is forgotten when this tab closes (you'll paste it again next session). A signer extension (Alby, nos2x) is safer and more convenient: the key never touches the page at all, and sign-in is remembered between visits.
